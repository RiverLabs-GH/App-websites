Read. Write. Organise.

Your agents write Markdown. Read it like it matters.

mark.O is a private, offline Markdown workspace for Mac. Read it properly, edit it live, keep every version, and review what your agents change.

Made for anyone who gets a Markdown file and just wants to read it: product managers, analysts, writers and team leads.

The problem

Agent output arrives as files. Most tools show you text.

The work comes back as Markdown, and more of what your agents know is Markdown too. You read it, correct it, approve it and send it on.

Any Markdown file or folder

  • Forty lines of raw #, | and ---.

    Tables, diagrams, math and code render the moment the file opens.

  • It rewrote a file you had already edited.

    Edits made outside the app are kept as their own versions. Compare any two, side by side.

  • It reworked the plan and the old one is gone.

    Restore any earlier version in one click.

  • You need to pass the result to a colleague.

    Export to PDF, HTML or EPUB in one step.

A folder of agent-written knowledge

  • Four hundred concepts, and nobody can say how they connect.

    See the whole bundle as a graph. Orphans and missing links stand out.

  • An agent edited a metric last night and nothing says so.

    It lands in a review queue. Open the diff, then verify it.

  • A runbook was true in March.

    Freshness dates show what is going stale, and you extend or deprecate it.

For everyone

Not a developer? Open a Markdown file and just read it.

Markdown is the plain-text format that AI tools and developers write in. In the wrong app it looks like clutter. mark.O shows it as the finished document, and you do not need to know Markdown to read it.

Markdown Reader

Read any Markdown file or folder the way it was meant to be seen.

Open a file and it reads like a finished document. Open a folder and work through it with tabs, an outline and find.

  • Everything renders

    Tables, task lists, math, diagrams and highlighted code, all bundled so it works offline.

  • It keeps up with the agent

    When a file changes on disk, mark.O refreshes it right there. No reopening.

  • Long reports, short trips

    An outline with reading progress, tabs, and find in page.

  • Opens Obsidian vaults

    Notes with [[links]], embeds, tags and callouts read correctly, so a vault opens as it was meant to.

OKF Reader

An OKF reader for knowledge bundles, with a human in the loop.

Open a folder of agent-written Markdown as an Open Knowledge Format bundle: a plain folder of linked notes with a standard shape. See it, review it, verify it, and keep it true.

  • Understand a bundle in a minute

    Every concept shows its type, tags, status, trust level and freshness. Footnotes resolve to their sources, and “Cited by” shows what points here.

  • See the shape

    A graph coloured by type and ringed by trust. Find the path between two concepts, or filter search by type, tag, status and trust.

  • Review before you rely on it

    Changed concepts land in Needs review. Open the diff since the last human check, then Verify. The history keeps both versions.

  • Edit without fear

    Change one front matter field and no other byte moves. A snapshot precedes every write, with Undo.

Trust labels are advisory. They tell people what has been looked at; they are not security. OKF is an open specification, and mark.O is not affiliated with Google.

AI assistant

Summarise it. Ask it. On your Mac.

When an agent hands you forty pages, mark.O gives you the gist and the answer, with the section each one came from.

  • Summarise in one click.

    A one-line summary and the key points, each linked to the section it came from. Pick Short, Medium or Detailed from a single button. Insert it at the top of the note, and undo it like any other edit.

  • Ask the note.

    “Who approves a 55 USD refund?” The answer comes from the note, names the section and line, and says so when the note does not say. Ask about the whole note or just the passage you selected.

  • Private by design.

    It runs on Apple Intelligence, on your Mac. Your notes are not sent to a server, and there is no account, key or subscription to set up.

Check it, don’t trust it: every point and every answer links to where it came from.
